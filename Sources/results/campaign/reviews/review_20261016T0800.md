I fixed a code bug that crashed both failed runs and put them back in the queue. Nothing has been rerun yet to confirm the fix works.

**What broke:** `j3_noniid_a0p3_ham10000_ehsfp_s0` crashed in round 1, and `j3_noniid_a0p7_ham10000_ehsfp_s0` crashed in round 10. Both hit the same `AttributeError: 'NoneType' object has no attribute 'shape'` at `classification/H-SFP/hierarchy.py:980`. My reading is that the cause is a client with no samples in that round, which can happen with the non-IID (Dirichlet) data split. Its per-class feature set is then empty, so the covariance matrix the shared-covariance step calculates comes back as `None`. A second spot (around line 1374) would also have failed on that `None` value. The plain H-SFP runs on the same splits don't use this step and are still running normally.

**Fix:** clients with no samples now send no covariance matrix and add nothing to the communication cost. Clients with data behave exactly as before. The edge-level code that combines the matrices already skipped missing ones, and settings are unchanged. I checked that the file compiles; I didn't run a test, to avoid spending GPU time.
